      Read this before trusting a prediction

      • Most training images are WM-811K-style wafer maps. Their spatial patterns were mapped onto the challenge's class names (for example Center became Shorts), so for those images the names are proxy labels, not electrical diagnoses.
      • Vias has only 23 images in total (4 in the test split), so its scores are very uncertain.
      • The confidence shown is a softmax score. It is not calibrated, and the model always picks one of the nine classes, even for an image that is not a wafer.
      • The split keeps every augmented copy of a wafer in one partition. The first version of this project leaked copies across train and test and mislabelled its outputs; the audit explains both.
